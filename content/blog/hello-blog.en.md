## What I'm working on

I got into the industry in 2014, starting as a Rails developer on the ZyXEL project run through an AWS reseller — my first project, serving a mostly European user base. I wrote backend code and test plans, and touched some AWS architecture work too. Later I shifted focus to the front end: mainly React.js, React Native, and Node.js.

Lately I've been using AI agents on a few projects to take repetitive work off my plate: I used Claude Code to collaborate on a real-estate website project, and at a data startup I used AI to help write BDD test plans.

Before I run out of AI tokens, I like to spend some on side projects — partly to put good data-privacy habits into practice, and partly to revisit my backend chops. Things like [PickleScout](https://github.com/iskWang/PickleScout), or training SDXL LoRAs with A1111/ComfyUI to generate images. Hermes Agent handles the day-to-day life admin for me.

## What I want to write here
